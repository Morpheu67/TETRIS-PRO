## 📸 Sobre o projeto

O **TETRIS PRO** é um projeto desenvolvido para explorar a criação de jogos para navegadores utilizando tecnologias web. A proposta é combinar a mecânica clássica de encaixe de peças com uma interface moderna e uma experiência de jogo acessível.

O projeto também faz parte de um processo de aprendizado sobre desenvolvimento de software, organização de código, testes e publicação de aplicações na internet.

## ✨ Funcionalidades

- 🧩 Tabuleiro clássico de Tetris.
- 🎨 Interface moderna e responsiva.
- 🔮 Visualização da próxima peça.
- 👻 Projeção da posição de queda da peça.
- 🏆 Sistema de pontuação.
- 📈 Progressão de níveis conforme a pontuação.
- 💾 Recorde salvo no navegador.
- ⏸️ Opção para pausar e continuar a partida.
- 🔄 Possibilidade de reiniciar o jogo.
- 📱 Controles adaptados para dispositivos móveis.
- 🎯 Detecção de fim de partida.

## 🎮 Controles

| Tecla | Ação |
|---|---|
| ⬅️ Seta para a esquerda | Move a peça para a esquerda |
| ➡️ Seta para a direita | Move a peça para a direita |
| ⬇️ Seta para baixo | Acelera a descida da peça |
| ⬆️ Seta para cima | Gira a peça |
| Espaço | Solta a peça rapidamente |
| P | Pausa ou retoma a partida |

*Os controles podem variar conforme a implementação e o dispositivo utilizado.*

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura do jogo.
- **CSS3:** layout, cores, efeitos visuais e responsividade.
- **JavaScript:** mecânica do jogo, movimentação das peças, colisões, pontuação e progressão de níveis.
- **GitHub:** hospedagem do código-fonte e controle de versões.
- **GitHub Pages:** publicação do jogo na internet.
